# 基于 STM32F103ZE 的运行时变量监控与在线调参系统

本提交包为嵌入式系统课程设计题目“主机接口软件”的最终材料。本项目参考 STM32CubeMonitor 的核心思想，采用一种低成本方式实现 STM32 运行时变量监控与在线调参功能：PC 端通过串口发送文本命令，STM32 在运行过程中返回变量表、读取变量值，并允许修改部分可写变量。

最终上板演示版本采用 no-LCD 瘦身固件工程，PC 端使用 XCOM V2.8 串口调试助手作为简易上位机界面。

## 1. 最终实现功能

本项目最终实现并演示了以下功能：

* PC 与 STM32 通过 USART 串口通信；
* 支持 `PING` 命令进行连通性测试；
* 支持 `LIST` 命令枚举运行时变量表；
* 支持 `GET <name>` 命令读取变量；
* 支持 `SET <name> <value>` 命令在线修改可写变量；
* 支持通过 `SET alarm_limit 280` 在线修改报警阈值；
* 支持通过 `GET alarm` 查看报警状态；
* 报警触发后，LED 与蜂鸣器产生板端反馈；
* 支持通过 `SET beep_en 0` 在线关闭蜂鸣器。

## 4. 最终固件打开与下载方式

1. 使用 Keil uVision5 打开：

```text
02_固件代码/RuntimeMonitor_Final/Projects/MDK-ARM/atk_f103_nolcd.uvprojx
```

2. 执行：

```text
Project → Rebuild all target files
```

3. 编译通过后，使用 ST-Link / JTAG 下载到正点原子战舰 STM32F103ZE 开发板。

4. 下载成功后，打开 XCOM V2.8 进行串口测试。

## 5. XCOM 串口参数

PC 端通过 CH340 USB 串口连接开发板，串口参数如下：

```text
波特率：115200
数据位：8
停止位：1
校验位：None
发送格式：ASCII 文本
16进制发送：不勾选
16进制显示：不勾选
发送新行：勾选
```

COM 口以 Windows 设备管理器显示为准，例如：

```text
COM3: USB-SERIAL CH340
```

## 6. 最终演示命令序列

最终演示视频按照以下顺序逐条发送命令：

```text
PING
LIST
GET temp_x10
SET alarm_limit 280
GET alarm
SET beep_en 0
```

对应功能如下：

| 命令                    | 功能                 |
| --------------------- | ------------------ |
| `PING`                | 测试 PC 与 STM32 串口通信 |
| `LIST`                | 枚举 STM32 内部变量表     |
| `GET temp_x10`        | 读取当前模拟温度           |
| `SET alarm_limit 280` | 将报警阈值在线修改为 28.0℃   |
| `GET alarm`           | 读取报警状态             |
| `SET beep_en 0`       | 在线关闭蜂鸣器            |

## 7. no-LCD 版本说明

项目开发过程中曾设计 LCD 显示接口，并尝试加入 LCD 相关驱动。但加入 LCD、FSMC/SRAM 等模块后，工程体积超过 Keil 非商业版本代码大小限制。

为保证最终演示稳定可复现，最终上板演示采用 no-LCD 瘦身版本：

```text
atk_f103_nolcd.uvprojx
```

该版本保留了项目核心功能：USART 在线变量监控、`PING / LIST / GET / SET` 协议命令、LED 报警反馈、蜂鸣器报警反馈和 KEY 驱动接入。LCD 接口在软件结构中作为预留接口说明，但最终演示版本未启用 LCD 显示。

## 8. 最终结论

本项目实现了一个基于 USART 的运行时变量监控与在线调参系统。PC 端通过 XCOM 发送文本命令，在 STM32 程序持续运行过程中读取变量、修改参数，并通过 LED 与蜂鸣器观察参数修改对系统状态的实时影响。

最终结果表明，本系统能够以较低成本复现主机接口软件的核心功能，即在不依赖 JTAG 调试器查看变量的情况下，通过串口完成 STM32 运行时变量查看与在线调参。
