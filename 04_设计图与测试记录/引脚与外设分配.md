# 引脚与外设分配

本项目基于正点原子战舰 STM32F103ZE 开发板实现运行时变量监控与在线调参功能。最终上板演示采用 `atk_f103_nolcd.uvprojx` 对应的 no-LCD 瘦身版本，主要通过 USART 串口完成 PC 端命令交互，并通过 LED / BEEP 等板端外设反馈系统状态。

## 1. 最终演示中使用的主要接口

| 模块 / 外设      | 引脚或接口              | 方向         | 最终用途                                |
| ------------ | ------------------ | ---------- | ----------------------------------- |
| CH340 USB 串口 | PC USB ↔ 开发板 CH340 | 双向         | PC 端 XCOM 与 STM32 通信                |
| USART1_TX    | PA9                | STM32 → PC | 向 XCOM 返回 `OK`、`DATA`、`VAR` 等响应     |
| USART1_RX    | PA10               | PC → STM32 | 接收 `PING`、`LIST`、`GET`、`SET` 等文本命令  |
| BEEP         | PB8                | STM32 → 外设 | 报警蜂鸣器，高电平响；可通过 `SET beep_en 0` 在线关闭 |

## 2. 已接入或预留的板端外设

| 模块 / 外设            | 引脚或接口          | 当前状态                 | 说明                                      |
| ------------------ | -------------- | -------------------- | --------------------------------------- |
| LED0               | PB5            | 已接入 / 自检使用           | 低电平点亮，可用于心跳指示或板端自检                      |
| LED1               | PE5            | 已接入 / 报警指示           | 低电平点亮，可用于报警状态指示                         |
| KEY0               | 以 `key.h` 定义为准 | 驱动已接入，最终视频未重点演示      | 可扩展为报警阈值增加                              |
| KEY1               | 以 `key.h` 定义为准 | 驱动已接入，最终视频未重点演示      | 可扩展为报警阈值减少                              |
| KEY2               | 以 `key.h` 定义为准 | 驱动已接入，最终视频未重点演示      | 可扩展为蜂鸣器使能切换                             |
| LCD                | FSMC / 8080 并口 | 接口预留，最终 no-LCD 版本未启用 | 曾设计显示变量状态，但因 Keil 非商业版本代码大小限制，最终演示版本未启用 |
| SysTick / HAL Tick | 内核定时节拍         | 已使用                  | 用于周期任务、模拟温度更新、报警判断等                     |

## 3. 最终演示命令与外设关系

| 串口命令                  | 功能                 | 板端现象                              |
| --------------------- | ------------------ | --------------------------------- |
| `PING`                | 测试 PC 与 STM32 通信链路 | 串口返回 `OK PONG`                    |
| `LIST`                | 枚举变量表              | 串口返回多行 `VAR ...`                  |
| `GET temp_x10`        | 读取当前模拟温度           | 串口返回当前温度变量                        |
| `SET alarm_limit 280` | 将报警阈值设置为 28.0℃     | 当 `temp_x10 >= alarm_limit` 时触发报警 |
| `GET alarm`           | 读取报警状态             | 返回 `DATA alarm 1 bool` 表示报警成立     |
| `SET beep_en 0`       | 在线关闭蜂鸣器使能          | 蜂鸣器关闭，但 `alarm` 报警状态不变            |

## 4. 说明

最终演示重点验证的是“PC 端通过串口在 STM32 运行过程中读取和修改变量，并实时影响板端状态”。其中 USART1 和 BEEP 是最终演示中的核心接口；LED0、LED1 已完成板级映射和自检，可作为运行状态或报警状态指示；KEY 驱动已接入，但未作为最终视频命令流程的重点演示内容；LCD 接口在软件结构中预留，但最终 no-LCD 演示版本未启用。
