# 串口协议说明

## 1. 物理层与串口参数

- 通信方式：USART 串口通信
- 波特率：`115200 bps`
- 数据位：`8 data bits`
- 校验位：`no parity`
- 停止位：`1 stop bit`
- 协议格式：ASCII 文本协议
- 结束方式：命令以回车换行结束，XCOM 中需勾选“发送新行”

## 2. 命令说明

| 命令 | 功能说明 | 典型返回 |
| --- | --- | --- |
| `PING` | 连通性测试 | `OK PONG` |
| `LIST` | 列出变量表 | 多行 `VAR ...`，最后返回 `OK LIST_END` |
| `GET <name>` | 读取变量，例如 `GET temp_x10` | `DATA <name> <value> <type/unit>` |
| `SET <name> <value>` | 修改可写变量，例如 `SET alarm_limit 280` | `OK SET <name> <value>` |
| `SET beep_en 0` | 在线关闭蜂鸣器使能 | `OK SET beep_en 0` |

## 3. 常用变量说明

| 变量名 | 含义 | 读写属性 |
|-----------|-----------------------------------|----------|
| `tick_s` | 系统运行秒数 | 只读 |
| `temp_x10` | 模拟温度，单位 0.1℃ | 可读 |
| `alarm_limit` | 报警阈值，单位 0.1℃ | 可写 |
| `alarm` | 报警状态（bool） | 只读 |
| `beep_en` | 蜂鸣器使能（bool） | 可写 |
| `key_count` | 按键计数 | 只读 |
| `run` | 系统运行使能（bool） | 可写 |

## 4. 演示逻辑说明

- `GET temp_x10` 用于读取当前模拟温度。
- `SET alarm_limit 280` 用于将报警阈值设置为 `28.0℃`。
- 当 `temp_x10 >= alarm_limit` 时，`alarm` 变为 `1`，LED 和蜂鸣器进入报警状态。
- `SET beep_en 0` 可以在线关闭蜂鸣器，但不会改变 `alarm` 的报警状态。

## 5. 示例交互

```text
PING
OK PONG

LIST
VAR tick_s ...
VAR temp_x10 ...
VAR alarm_limit ...
VAR alarm ...
VAR beep_en ...
VAR key_count ...
VAR run ...
OK LIST_END

GET temp_x10
DATA temp_x10 312 0.1C

SET alarm_limit 280
OK SET alarm_limit 280

GET alarm
DATA alarm 1 bool

SET beep_en 0
OK SET beep_en 0
```

以上交互与最终演示一致：使用 XCOM 通过 USART 对 no-LCD 固件进行在线变量监控，并演示 LED 报警、蜂鸣器报警和在线关闭蜂鸣器。
