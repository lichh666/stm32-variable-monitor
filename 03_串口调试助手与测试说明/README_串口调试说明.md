# 串口调试说明

本项目最终演示版本使用 **XCOM V2.8** 作为 PC 端简易上位机/串口调试界面，通过串口命令完成在线变量监控与控制测试。

## 1. 工具与连接方式

- 工具名称：XCOM V2.8
- 连接方式：开发板通过 **CH340 USB 转串口** 连接电脑
- 串口号：以 Windows 设备管理器显示为准，例如 `COM3: USB-SERIAL CH340`

## 2. 串口参数设置

- 波特率：`115200`
- 数据位：`8`
- 停止位：`1`
- 校验位：`None`
- 发送格式：ASCII 文本
- 16 进制发送：不勾选
- 16 进制显示：不勾选
- 发送新行：勾选

## 3. 基本测试流程

1. 打开 XCOM V2.8。
2. 选择 CH340 对应的 COM 口。
3. 设置串口参数为 `115200, 8N1, None`。
4. 点击“打开串口”。
5. 按下开发板 `RESET` 按键。
6. 观察串口启动信息，确认出现 `BOOT STM32_RUNTIME_MONITOR 1.0` 以及 `HELP` 相关提示。
7. 按 [测试命令序列.txt](测试命令序列.txt) 中的顺序逐条发送命令并观察返回结果。
8. 发送 `SET alarm_limit 280` 将报警阈值设为 28.0℃，触发 LED 和蜂鸣器报警。
9. 发送 `SET beep_en 0` 在线关闭蜂鸣器（报警状态不变，仅关闭蜂鸣器）。

## 4. 最终演示版本说明

最终演示使用 `atk_f103_nolcd.uvprojx` 对应的 no-LCD 固件工程，重点展示以下功能：

- USART 在线变量监控
- LED 报警指示
- 蜂鸣器报警
- 在线关闭蜂鸣器

因此，老师或同学复现实验时，只需连接开发板串口并使用 XCOM 按命令顺序测试即可。
