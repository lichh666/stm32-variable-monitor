# 演示视频说明

本文件说明《基于 STM32F103ZE 的运行时变量监控与在线调参系统》最终演示视频的内容、命令顺序和验证目标。

## 1. 演示视频名称

建议视频文件命名为：

```text
学号_姓名_STM32运行时变量监控系统_演示视频.mp4
```

如无特殊命名要求，也可命名为：

```text
STM32运行时变量监控系统_演示视频.mp4
```

## 2. 最终演示版本

本项目最终演示采用 no-LCD 固件版本：

```text
atk_f103_nolcd.uvprojx
```

PC 端使用 XCOM V2.8 串口调试助手，通过 CH340 USB 串口与 STM32F103ZE 开发板通信。

串口参数为：

```text
115200
8 data bits
1 stop bit
None parity
ASCII 文本
发送新行：勾选
```

## 3. 视频演示命令顺序

演示视频中按照以下顺序逐条发送命令：

```text
PING
LIST
GET temp_x10
SET alarm_limit 280
GET alarm
SET beep_en 0
```

## 4. 各命令对应的演示目的

| 命令                    | 演示目的                   | 预期现象                              |
| --------------------- | ---------------------- | --------------------------------- |
| `PING`                | 验证 PC 与 STM32 串口通信是否正常 | 返回 `OK PONG`                      |
| `LIST`                | 验证 STM32 能否返回运行时变量表    | 返回多行 `VAR ...`，最后返回 `OK LIST_END` |
| `GET temp_x10`        | 读取当前模拟温度变量             | 返回 `DATA temp_x10 ... 0.1C`       |
| `SET alarm_limit 280` | 在线修改报警阈值为 28.0℃        | 返回 `OK SET alarm_limit 280`       |
| `GET alarm`           | 读取报警状态                 | 报警触发时返回 `DATA alarm 1 bool`       |
| `SET beep_en 0`       | 在线关闭蜂鸣器使能              | 蜂鸣器关闭，但报警状态不变                     |

## 5. 视频中需要体现的关键结果

演示视频主要用于证明以下功能：

1. PC 端能够通过 XCOM 向 STM32 发送串口命令；
2. STM32 能够正确解析 `PING`、`LIST`、`GET`、`SET` 命令；
3. PC 端能够在 STM32 程序运行过程中读取变量；
4. PC 端能够在线修改报警阈值 `alarm_limit`；
5. 修改报警阈值后，系统报警状态 `alarm` 能够变化；
6. 报警状态触发后，LED 与蜂鸣器产生板端反馈；
7. 发送 `SET beep_en 0` 后，蜂鸣器可以在线关闭。

## 6. no-LCD 说明

本项目开发过程中曾设计 LCD 显示接口，但由于 Keil 非商业版本代码大小限制，最终上板演示采用 no-LCD 瘦身版本。最终视频重点展示 USART 在线变量监控、GET/SET 在线调参、LED 报警和蜂鸣器报警反馈。

因此，演示视频中不包含 LCD 显示效果。

## 7. 视频结论

该演示视频表明，本系统能够在 STM32 程序持续运行的情况下，通过 PC 端串口命令读取和修改运行时变量，并将参数修改结果实时反映到 LED 与蜂鸣器等板端外设上，完成了运行时变量监控与在线调参的核心功能验证。
